# Project instructions

## Progress log

After each prompt, update `PROGRESS.md` with what was done.

- Group entries by day under a `## YYYY-MM-DD` heading. Use today's date, and create the heading if it doesn't exist yet.
- Add one bullet per prompt: what was done or decided, plus any files changed.
- Append to today's section; never rewrite earlier days.
- Keep a short `**Summary:**` line at the top of each day's section, and update it as the day goes on so it shows that day's overall progress.
- Skip the update for prompts that changed nothing and were only questions.
